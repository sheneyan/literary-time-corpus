# Initial repository design

## Goal

Publish a documentation-only first version of Literary Time Corpus that states
the project's scope, exact-minute semantics, provenance model, rights boundary,
and pilot evaluation requirements without ingesting or publishing excerpts.

## Repository surface

- `README.md` is the public entry point.
- `LICENSE` applies MIT to project-authored software and documentation.
- `DATA_RIGHTS.md` prevents the root software license from being mistaken for a
  blanket license over literary text or future dataset contents.
- `docs/project-brief.md` is the canonical project boundary and approved pilot
  design input.

## Release boundary

The initial commit contains no literary excerpts, downloaded ebooks, extraction
software, generated corpus data, or product integration. Those require a later
approved pilot design and implementation plan.
